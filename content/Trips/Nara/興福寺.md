## 歷史

| 年代            | 階段   | 主要事件                                                                               |
| ------------- | ---- | ---------------------------------------------------------------------------------- |
| 4–5世紀         | 印度   | 瑜伽行派（唯識）由無著、世親開出。後世法相宗以世親《唯識三十頌》為根本論。                                              |
| 貞觀19年（645）    | 中國成立 | 玄奘自印度歸唐，編譯護法一系注釋為《成唯識論》。弟子窺基（慈恩大師）據此開宗，故以玄奘為開山、窺基為宗祖。亦稱唯識宗、慈恩宗、中道宗。                |
| 約7世紀後半        | 中國分流 | 同門圓測一系也曾被視為廣義法相宗，門人道證時一度興盛；開元年間（713–741）併入窺基系。                                     |
| 武周（690–705）以後 | 中國衰落 | 教義近於印度原典、體系繁複，不敵法藏華嚴宗之勢。安史之亂與會昌廢佛後再受重創，宋、元之際作為宗派退出中國佛教史。                           |
| 白雉4年（653）     | 日本初傳 | 道昭入唐師事玄奘，歸國後於飛鳥法興寺弘傳。日本以道昭為開宗者，法相宗為現存最古宗派之一。此系後稱南寺傳。                               |
| 齊明天皇4年（658）   | 第二傳  | 智通、智達入唐傳法。平城京元興寺建立後教線移入該寺，稱元興寺傳、南傳。道昭門下有道賀、行基。                                     |
| 大寶3年（703）     | 第三傳  | 智鳳、智雄等入唐，師事窺基再傳弟子智周。此系後為北寺傳（興福寺・藥師寺）的來源。                                           |
| 養老元年（717）     | 第四傳  | 義淵弟子玄昉入唐，從濮陽智周學法相，歸國後於興福寺興宗，奠定興福寺法相（北傳）。門下有慈訓、善珠。                                  |
| 8–9世紀         | 奈良隆盛 | 列入南都六宗。興福寺學僧輩出，賢憬、修圓、德一最著。修圓於寺內建傳法院，一派稱傳法院門徒。元興寺雖有護命、明詮等碩學，其法相後併入興福寺，興福寺遂成專修法相的寺院。 |
| 平安初期          | 教諍   | 德一與天台宗最澄展開「三一權實諍論」。                                                                |
| 平安末期以降        | 中世學僧 | 藏俊、貞慶、覺憲、信圓等相繼出於興福寺系。                                                              |
| 1882年         | 近代寺格 | 興福寺、藥師寺、法隆寺三寺定為大本山。                                                                |
| 1950年         | 分立   | 法隆寺改稱聖德宗並離脱。此後由興福寺、藥師寺兩本山統括。                                                       |
| 1965年         | 再分立  | 京都清水寺獨立，號北法相宗。                                                                     |
| 1970年         | 新寺   | 藥師寺別院聖光寺建立。                                                                        |
| 現在            | 現況   | 仍以興福寺、藥師寺為兩大本山。南都六宗中至今存續者，主要是律宗、華嚴宗與法相宗。                                           |

## 伽藍

![[_Misc/Attachment/興福寺-1791119320089.webp]]

### 中金堂

![[_Misc/Attachment/興福寺-1791119729779.webp|599]]
寄棟造、單層裳階、本瓦葺，面闊約九間，2018年10月按創建規模落成。和銅3年（710）藤原不比等著手興建，約714年完成，是全寺中心佛堂。其後至少七度燒毀；正保、享保2年（1717）大火後只建縮小的假金堂，直到現代（2018 年）才正式復興。

- **釋迦如來坐像**（本尊）：文化8年（1811）佛師赤尾右京作，木造、高約2.8公尺。佛教創始者，現世說法之佛。
- **藥王、藥上菩薩**：建仁2年（1202）作，重要文化財，各高約3.6公尺。兄弟菩薩，藥師信仰中的脅侍，象徵療癒與供養。
- **四天王**：鎌倉時代，國寶。持國、增長、廣目、多聞，各守一方，鎮護國土。此組2017年自南圓堂移入。

### 東金堂

![[_Misc/Attachment/興福寺-1791120037394.webp|540x345]]
國寶。面闊七間、進深四間，單層寄棟、本瓦葺，是現存室町期佛堂。神龜3年（726）聖武天皇為元正太上天皇病癒祈願而建；應永18年（1411）與五重塔同焚，應永22年（1415）再建，為第五代。堂內常時可見約二十尊像。

- **銅造藥師如來**（本尊）：室町重建，重要文化財。東方淨琉璃世界教主，誓願除病延壽。
- **日光、月光菩薩**：奈良時代白鳳樣，自飛鳥山田寺移入，躲過應永火災。分別象徵日、月，為藥師脅侍。
- **文殊菩薩、維摩居士**：建久7年（1196）定慶作，國寶。文殊表智慧；維摩是在家居士，於《維摩經》中與文殊論法，象徵不離世間而成道。
- **四天王**：平安初期，國寶，形體厚重。
- **十二神將**：約建永2年（1207），國寶。藥師眷屬，各配十二時辰，護持修藥師法者。

### 西金堂

已不存。

天平6年（734）光明皇后為母親橘三千代追善所建。治承4年（1180）平重衡兵火後曾重建，享保2年（1717）再焚，此後未復原，只剩基址。本尊釋迦與周圍的八部眾、十大弟子原在此堂，今多藏於國寶館。

### 五重塔

![[_Misc/Attachment/興福寺-1791120184699.webp]]
國寶。三間五重塔婆（塔婆即）、本瓦葺，高50.1公尺，奈良現存最高塔。天平2年（730）光明皇后創建，應永33年（1426）第六次再建，初層斗栱仍留奈良式三手先。內部通常不公開。初層四方各安一組室町時代三尊：東藥師、南釋迦、西阿彌陀、北彌勒，合稱四方佛，對應現世、過去、西方淨土與未來成佛。

### 北圓堂

![[_Misc/Attachment/興福寺-1791120246712.webp|507x324]]
國寶。八角圓堂、單層本瓦葺，和法隆寺夢殿同型，是境內最古建築之一。養老5年（721）元明、元正天皇命長屋王為藤原不比等一周忌建立；承元4年（1210）前後再建。內部僅特別公開時可入。

- **彌勒佛坐像**（本尊）：建曆2年（1212）前後運慶工房作，國寶。未來佛，今在兜率天，將下生說法。
- **無著、世親立像**：同工房，國寶。法相宗所宗的印度唯識論師兄弟，世親即《唯識三十頌》作者，像容寫實如肖像。
- **法苑林、大妙相菩薩**：室町時代脅侍，彌勒淨土的兩大菩薩。
- **木心乾漆四天王**：延曆10年（791），國寶，原屬大安寺。

### 南圓堂

![[_Misc/Attachment/興福寺-1791119932516.webp|452x289]]
重要文化財。八角圓堂，正面附唐破風拜所，本瓦葺，江戶和樣。弘仁4年（813）藤原冬嗣為父內麻呂追善創建；現堂寬保元年（1741）立柱、寬政元年（1789）落成，為第四代。堂內秘佛，例年僅10月17日大般若轉讀會開帳。

- **不空羂索觀音**：文治5年（1189）康慶一門作，高336公分，三眼八臂，國寶。手持羂索，象徵救度不失。
- **四天王、法相六祖**：同年康慶工房，國寶。六祖是日本法相傳承中的六位學僧（傳玄昉、善珠等），坐像如高僧肖像，直接對應該宗法脈。

### 三重塔

![[_Misc/Attachment/興福寺-1791119954632.webp|308]]
國寶。三間三重塔婆、本瓦葺，高約19公尺，初層母屋偏大，輪廓穩重。康治2年（1143）崇德天皇中宮皇嘉門院創建，鎌倉初期再建，與北圓堂同為境內最古一層。內部不公開，無常設本尊可參拜。
