東大寺是華嚴宗總本山，正式寺號為金光明四天王護國之寺。中軸是南大門、中門、大佛殿、講堂跡；東山上一帶稱上院，有三月堂、二月堂。治承4年（1180）平重衡、永祿10年（1567）三好・松永兩次兵火燒掉大半，現存堂塔多是鎌倉或江戶再建。

## 歷史

| 年代                  | 事件                                                              |
| ------------------- | --------------------------------------------------------------- |
| 天平5年（733）前後         | 前身金鐘山寺已在東山。法華堂（三月堂）以此為上限，是現存最古堂，相傳日本最早講《華嚴經》之處。                 |
| 天平13年（741）          | 聖武天皇下國分寺、國分尼寺詔。東大寺後來成為大和國分寺，正式名金光明四天王護國之寺。                      |
| 天平15年（743）          | 紫香樂宮下盧舍那大佛造顯詔，據《華嚴經》，號召「一枝草、一把土」協力。                             |
| 天平17年（745）          | 還都平城。鑄造在金鐘山寺寺域重開，由造東大寺司主持。                                      |
| 天平勝寶元年（749）         | 佛身經三年八次鑄接完成。聖武表明以《華嚴經》為根本。                                      |
| 天平勝寶4年（752）         | 大佛殿落成，開眼供養。導師是菩提僊那。與聖武、行基、良辨合稱四聖建立。坐高14.98公尺。創建殿面闊十一間，約86–88公尺。 |
| 天平勝寶6–7年（754–755）   | 鑒真到日，於戒壇院築戒壇，日本始有正式授具足戒之處。                                      |
| 齊衡2年（855）           | 地震，大佛頭墜落，隨後修復。                                                  |
| 平安時代                | 殿舍屢因災火重修；以莊園維持修造與教學。                                            |
| 治承4年（1180）          | 平重衡南都燒討，大佛殿與大半伽藍焚毀。                                             |
| 養和元年（1181）          | 重源任勸進職，引入宋工陳和卿與大佛樣。                                             |
| 文治元年（1185）          | 大佛補鑄頭與左手，再次開眼。                                                  |
| 建久6年（1195）          | 鎌倉大佛殿落慶，規模仍近創建。翌年脇侍與四天王造成。                                      |
| 正治元年（1199）          | 南大門重建，大佛樣代表作。建仁3年（1203）運慶、快慶一門作仁王。                              |
| 永祿10年（1567）         | 三好、松永兵火。大佛殿、戒壇堂等再焚。大佛露天近百年。                                     |
| 寬文7年（1667）          | 二月堂於修二會中失火，兩年後再建為現堂。                                            |
| 貞享元年（1684）          | 公慶上人獲幕府許可重修。                                                    |
| 元祿5年（1692）          | 補鑄佛頭與十八枚蓮瓣，開眼。                                                  |
| 寶永6年（1709）          | 現大佛殿落慶。面闊縮到七間、約57公尺，進深與高度近舊規。中門、回廊又過約三十年才完工。                    |
| 明治39–45年（1906–1912） | 解體修理，內部加鐵骨。                                                     |
| 昭和48–55年（1973–1980） | 屋頂大修，1980年落慶法要。                                                 |

## 伽藍

![[_Misc/Attachment/東大寺-1791125801338.webp]]

### 大佛殿（金堂）

![[_Misc/Attachment/東大寺-1791126841093.webp|563x317]]
國寶。單層裳階付、寄棟、本瓦葺，正面七間、側面五間，東西57公尺、南北50.5公尺、高48.7公尺。以鎌倉傳入的大佛樣為底，貫木穿柱。天平勝寶4年（752）開眼時面闊十一間、約86至88公尺；現堂是寶永6年（1709）公慶上人重建，面闊縮到約六成。1912年大修時內部加了鐵骨。

- **盧舍那佛**（本尊，國寶）：坐高14.98公尺，銅造。華嚴教主，智慧與慈悲的光明遍照，不是歷史上的釋迦，而是《華嚴經》裡悟道當下的法身。天平勝寶元年（749）鑄成，752年由菩提僊那開眼。頭在855年地震墜落，1180年兵火後由宋人陳和卿補鑄，江戶再建時佛頭與十八枚蓮瓣又補鑄。台座蓮瓣上的毛雕是蓮華藏世界。
- **虛空藏菩薩、如意輪觀音**：江戶補作的脅侍。虛空藏主智慧與福德如虛空；如意輪是觀音變化身，持輪與寶珠，滿願。創建時脅侍配置與此不同。
- **四天王**：持國、增長、廣目、多聞，守四方。堂內另有八角燈籠（國寶，奈良時代），火袋浮雕奏樂的音聲菩薩。

### 南大門

![[_Misc/Attachment/東大寺-1791126974777.webp|553x311]]
國寶。五間三戶、二重門，入母屋、本瓦葺，高約25.5公尺。外觀兩層，內部通到頂，不施天井。正治元年（1199）重源重建，是大佛樣代表作。其前的平安門在應和2年（962）被颱風吹倒。

- **金剛力士**（仁王，國寶）：建仁3年（1203）運慶、快慶一門作，高約8.4公尺，僅七十餘日完成。阿形張口、吽形閉口，象徵宇宙起止。此處兩像相對而立，左右也與常見配置相反。

### 中門與回廊

江戶再建，中門是大佛殿前的樓門，左右延伸回廊。門內亦有仁王。創建時這一圈回廊把金堂圍成獨立院落；現回廊要到寬保年間（約1740）才完工。

### 法華堂（三月堂）

![[_Misc/Attachment/東大寺-1791126909525.webp|553x311]]
國寶，境內最古佛堂。面闊五間、進深八間。後方正堂是奈良寄棟、平入，約8世紀中葉；前方禮堂是建久、正治間（1199前後）重源加建的入母屋、妻入。最初是正堂與禮堂分開的雙堂。前身金鐘寺的主要堂，相傳日本最早講《華嚴經》之處，舊名羂索堂；因三月修法華會得今名。

- **不空羂索觀音**（本尊，國寶）：乾漆，三眼八臂，手持羂索，象徵救度不失。
- **梵天、帝釋天**：國寶。梵天是印度創造神被收為護法；帝釋天即因陀羅，忉利天主。
- **四天王、金剛力士**：國寶，同為奈良塑像或乾漆。力士忿怒相，與南大門仁王不是同一對。
- **執金剛神**：國寶，秘佛，僅12月16日開扉。手舉金剛杵，鎮護佛敵。相傳是良辨的護法，也與修二會相關。
- 日光、月光、吉祥天、辯才天已移到東大寺博物館。吉祥天主福德，辯才天主音樂與辯才。

### 二月堂

![[_Misc/Attachment/東大寺-1791127003510.webp|577x325]]
國寶。懸崖上的佛堂，懸造，本瓦葺。舊曆二月修修二會（取水）得名。1180、1567兩次兵火都倖存，寬文7年（1667）取水失火燒毀，兩年後再建為現堂。

- **大觀音、小觀音**：兩尊十一面觀音，絕對秘佛，任何人不得見。十一面觀音以十面加本面，表觀一切眾生苦而施救。修二會即向此二像悔過、祈求天下安穩。堂下有若狹井，傳說與若狹的水相通。

### 四月堂（三昧堂）

![[_Misc/Attachment/東大寺-1791127044187.webp|583x328]]
重要文化財。小規模二重堂，寄棟、本瓦葺。寬文、元祿間（約1681，後改屋頂）再建。1021年已有在此修法華三昧的記錄，故名三昧堂；四月行法會則稱四月堂。本尊是秘佛千手觀音，千手表遍救一切苦。

### 戒壇院戒壇堂

![[_Misc/Attachment/東大寺-1791126944703.webp|524x295]]
江戶享保年間（1730年代）再建，入母屋、本瓦葺。鑒真於天平勝寶7年（755）在此築戒壇，是日本正式授具足戒的三戒壇之一。堂心是三重戒壇，不是佛像。

- **四天王**（國寶）：奈良時代塑像，各高約1.6公尺。原不在此，曾安於已不存的中門堂、後移指図堂，享保再建時才入戒壇堂。作風與法華堂諸像相近，有一說原本就是法華堂須彌壇下層的一組。

### 戒壇院千手堂

![[_Misc/Attachment/東大寺-1791127331868.webp|533x300]]
戒壇院旁的小堂，本尊千手觀音。

### 開山堂

![[_Misc/Attachment/東大寺-1791127080612.webp|527x297]]
國寶建築（鎌倉），內陣有八角廚子。祀初代別當良辨。寬仁3年（1019）首辦法要時創建，現堂是鎌倉再建。良辨坐像（國寶）是11世紀肖像，秘佛，僅12月16日良辨忌開扉。旁有良辨杉，傳說幼年良辨被鷲叼到這棵杉上。

### 轉害門

![[_Misc/Attachment/東大寺-1791127364428.webp|570x321]]
國寶。三間一戶八腳門，切妻、本瓦葺，天平寶字前後（8世紀中）的創建遺構，兵火未及。面向佐保路，故又名佐保路門；傳說平景清埋伏於此，又稱景清門。每年10月5日手向山八幡宮的轉害會在此舉行。

### 鐘樓

![[_Misc/Attachment/東大寺-1791127260482.webp|523x294]]
鎌倉再建，大佛樣。懸治承兵火後重鑄的梵鐘（國寶），高約3.9公尺、重約26噸，是日本最重的一類梵鐘。

### 大湯屋

![[_Misc/Attachment/東大寺-1791127226669.webp|573x323]]
鎌倉，重源所建的僧侶澡堂，大佛樣。內部留蒸氣浴的裝置。

### 俊乘堂、行基堂、念佛堂

![[_Misc/Attachment/東大寺-1791127140896.webp|520x293]]![[_Misc/Attachment/東大寺-1791127169778.webp|522x294]]![[_Misc/Attachment/東大寺-1791127194392.webp|520x293]]
鐘樓丘一帶的小堂。俊乘堂祀中興勸進重源坐像（國寶），重源以六十餘歲任勸進，引入宋工與大佛樣，1195年大佛殿落慶。行基堂祀行基菩薩坐像，行基組織民眾參與鑄大佛，東大寺稱「四聖建立」（聖武、行基、良辨、菩提僊那）。念佛堂是淨土系念佛堂。

### 不動堂、指図堂

![[_Misc/Attachment/東大寺-1791127107661.webp|552x311]]
不動堂在二月堂下方，本尊不動明王，密教降伏尊，背火焰、持劍與羂索。指図堂在大佛殿東，因保存伽藍圖樣得名；戒壇堂四天王曾暫安於此。

### 講堂跡、東西塔跡

講堂在大佛殿正北，只剩基壇，是僧眾講經之處。東西塔是創建時大佛殿南方的兩座七重塔，只剩土壇。東塔跡在鏡池東南那塊方壇。
